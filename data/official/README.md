# 公式の山岳標高データの置き場所

国土地理院「日本の主な山岳標高」（https://www.gsi.go.jp/kihonjohochousa/kihonjohochousa41139.html）から
ダウンロードしたファイルをこのフォルダに置くと、`npm run master:elevation` が山名データと突合して標高を付けます。

- **GeoJSON 版を推奨**（各山の緯度・経度が入っているため、座標で安全に突合できる）。CSV 版は緯度・経度の列がある場合のみ使用
- 突合条件: 山名位置から 150m 以内 ＋ 山名・山頂名・読みのいずれかが一致。曖昧な候補は採用しない（名前だけでは突合しない）
- ネットワーク不要で突合できます: `npm run master:elevation -- --offline --no-dem`（DEM の値は前回分を保持）
- 出典: 国土地理院「日本の主な山岳標高」（国土地理院コンテンツ利用規約に従い出典を明示）

ファイル名は変更しなくて構いません（.geojson / .json / .csv を自動判定。Shift_JIS も可）。
